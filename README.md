# IntentWeave

IntentWeave is a diagramming tool intended to support iStar 2.0 modeling, primarily for education and research. It is inspired by tools such as [Creative Leaf](https://www.cs.utoronto.ca/~amgrubb/leaf/) and [OpenOME](https://www.cs.toronto.edu/km/istar/).

The tool was created by prompting Codex, together with software engineering practices including requirements, testing, and version control. The owner has not carefully reviewed the source code and makes no guarantee about the tool's function or performance.
