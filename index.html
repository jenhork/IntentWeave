How to use the palette

Choose an element, then click the canvas. You can also drag it onto the canvas. Drag elements into or out of an actor boundary to change where they belong. Drag the actor circle to move it with its elements. Select an element or actor and drag its blue handle, or use its size control to resize it. Select an actor to collapse or expand it.

Choose a link, then select the source and destination elements or actor circles. For a dependency, select the dependent first, then the element it depends on. Press Escape to cancel.

Drag elements to move them. Select an element to change its name. Use arrow keys to move a focused element.
